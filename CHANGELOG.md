## Berry Pouch Changelog
^^^
--- 
## v0.6.2
- Made completely new models and textures for the Pokeball Launcher.
- Added a custom Advancements tab to allow players to quickly get familiar with the mod's features and mechanics.
- Updated language files.
- Fixed GUI position.

## v0.6.1
- Added the Apricorn Basket for quickly harvesting ripe Apricorns and Berries.
- Remove Forge Config API Port from the Fabric version's dependencies.

## v0.6.0
- Fixed multiplayer crashes caused by incorrect Mixin class usage.
- Fixed missing sound effects when picking up Poké Balls.
- Fixed missing localization keys.
- Fixed six types of berries not auto-collecting into the bag.

## v0.5.3
- Fixed a concurrency issue during NeoForge client information registration.
- Removed Small Pouch; refactored data structures and assets for the Large Pouch. Added four tags for berry categorization.
- Added 16 universal slots for items with the berrypouch:other_bait tag, supporting Poké Bait.
- Changed berry marking hotkey from Shift + Left Click to S + Left Click.
- Updated localizations and translation keys (now includes English and Chinese).
- Added new item: Poké Ball Launcher. Can store 9 stacks of Poké Balls with seamless switching and launching.

## v0.4.3
- Update Cobblemon 1.7 support.
- The missing Eggant Berry slot is normal; it’s planned to be added in version 0.5.

## v0.4.2
- Fixed the duplication issue that occurred when storing berries in the pouch.

## v0.4.1
- Fixed the issue of shortcut key class not properly registered in the Neoforge version.
- Fixed the issue of berries disappearing from the pouch when using the Inventory Sorter mod.
- Fixed the issue of missing dependencies in the Fabric version.
- Added localization for 6 languages.
- Added a new shortcut key to toggle auto bait filling, which is set to \ by default.

## v0.4.0
- Added a HUD that only appears when holding a fishing rod.
- Added a feature to mark berry types; you can now switch only within the marked list. Default is Shift + Left Click.

## 0.3.0
- Fixed the multiplayer issue in version 0.2.0.
- Fixed some bugs encountered during testing.
- Corrected language files and key names.
- Added Accessories as a dependency.
- Added a dedicated accessory slot and shortcut key, default is P.
- Added bait switching support for the Cobblemon fishing rod, default is [ and ].

## 0.2.0
- Updated assets and project icon.
- Modified the small bouch recipe and fixed the large bouch recipe.
- Added sound effects for opening and closing the pouch.
